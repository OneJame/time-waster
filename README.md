# Time Waster!

Heyo! This is a silly little game I made entirely in python. 

Originally this was made to practice my (at the time) new python skills and rack in a few hours of coding (that's how it got it's name!) but 5 hours of work later, this project is actually pretty polished and I'm really proud of it!

## To run the project:

1. Download the main.py file
2. in your terminal run python [location of file] if your on windows or python3 [location of file] on mac and most linux
